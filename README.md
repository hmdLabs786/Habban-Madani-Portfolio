## // ABOUT

This repository holds the source for my personal portfolio — a single self-contained `index.html`, no build step, no framework. It's built around a dark, circuit-inspired visual language with glass-panel cards, scroll-driven reveals, and a terminal-style loading sequence, meant to reflect the kind of engineering- and product-focused work I actually do rather than a generic template.

## // WHAT'S INSIDE

- **Hero** — large gradient typography, floating code-style chips, HUD-style status readout
- **About** — identity card with photo, expertise / education / certifications / goal panels
- **I Build** — a short scroll-reveal sequence of what I build (web, mobile, backend, AI, automation)
- **Creations** — an auto-looping project carousel with a flagship spotlight (IlmAI) and a modal case-study view (problem → solution → stack → GitHub link) for each project, pulled straight from each repo
- **Stack** — a categorized grid of the technologies I actually use
- **Experience** — internship history with a skills breakdown
- **Contact** — Email, GitHub, LinkedIn, Facebook and Instagram as a single linked table
- **Resume download** — CV embedded directly in the page, no external file needed
- A terminal-style preloader, a vertical scroll-spy nav on desktop and a hamburger menu on mobile/tablet, and full reduced-motion support

## // TECH STACK

| Layer | Tools |
|---|---|
| Structure / Styling | HTML5, CSS3 (custom properties, CSS Grid/Flexbox, no preprocessor) |
| Animation | [GSAP](https://gsap.com/) + ScrollTrigger |
| Logic | Vanilla JavaScript (no framework, no bundler) |
| Assets | Photo and résumé embedded as inline base64 — fully self-contained, no external file dependencies |

## // RUN LOCALLY

No install, no build step — it's one HTML file.

```bash
git clone https://github.com/hmdLabs786/<this-repo>.git
cd <this-repo>
open index.html   # or just double-click it / drag it into a browser
```

To deploy: push to **GitHub Pages** (Settings → Pages → deploy from branch), or drag the file into **Vercel** / **Netlify** for an instant live link.
